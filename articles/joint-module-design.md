# 关节模组设计笔记

## 项目背景

这是一个高扭矩密度关节模组的完整设计项目，从电机选型、减速器设计、编码器集成到驱动电路开发的全流程记录。

## 设计目标

- **扭矩密度**：>50 N·m/kg
- **精度**：±0.1°
- **响应时间**：<50ms
- **工作温度**：-10°C ~ 60°C

## 核心模块

### 1. 电机选型

选择无刷直流电机（BLDC），主要参数：
- 额定功率：200W
- 额定扭矩：2 N·m
- 额定转速：3000 RPM
- 效率：>85%

### 2. 减速器设计

采用谐波减速器方案：
- 减速比：50:1
- 传动效率：65%
- 回程间隙：<3'

### 3. 编码器集成

使用多圈绝对值编码器：
- 分辨率：16bit
- 通信协议：CANopen
- 工作温度：-20°C ~ 70°C

### 4. 驱动电路

基于 STM32G4 的 FOC 控制器：
- 支持 FOC 矢量控制
- CAN 通信接口
- 过流/过压保护
- 实时温度监测

## 性能指标

| 指标 | 数值 |
|------|------|
| 最大扭矩 | 100 N·m |
| 连续扭矩 | 50 N·m |
| 最大转速 | 60 RPM |
| 定位精度 | ±0.05° |
| 重复精度 | ±0.02° |
| 响应时间 | 30ms |

## 关键技术方案

### FOC 控制算法

采用磁场定向控制（Field Oriented Control）：
- 实时电流环控制
- 速度环 PID 调节
- 位置反馈闭环

### 热管理

- 铝合金散热壳体
- 导热硅脂填充
- 温度传感器实时监测
- 过温自动降功率

### 可靠性设计

- 双路冗余编码器
- 故障自诊断功能
- 安全状态自动切换
- 完整的故障日志记录
